# tax-docs

Local repository for tax documents and related files, with a Ramp-inspired design system for web development.

## Project structure

```text
design-system/   Design tokens, CSS, and documentation
src/             App entry and styles
index.html       Web app shell
```

## Development

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
npm run preview
```
